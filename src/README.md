# Что делает каждый файл в src

| Файл | Назначение |
|---|---|
| `ZandatsuScript.cs` | Главный управляющий код: настройки, обработка ударов и движения клинка, запуск и завершение разрезов противников. |
| `Snapshot.cs` | Сохраняет модель и текущую позу противника; подготавливает данные для расчётов в фоновом потоке. |
| `Skeleton.cs` | Описывает физические части тела, их суставы и коллайдеры; связывает кости модели с частями рэгдолла. |
| `MeshSlicer.cs` | Разрезает геометрию плоскостью, строит поверхности срезов, заливку под бронёй и геометрию обожжённых краёв. Также содержит структуры данных меша и работу с весами костей. |
| `CutWork.cs` | Организует фоновый расчёт разреза тела: определяет затронутые части, разделяет результат на куски, распределяет массу и подбирает коллайдеры. |
| `Hybrid.cs` | Изменяет оставшуюся часть противника после разреза, сохраняя её игровым персонажем. Хранит исходное состояние для восстановления при удалении из мира. |
| `Survival.cs` | Позволяет противнику выжить после потери конечности: кровотечение, смерть по таймеру, падение без ноги и запрет использования утраченной руки. |
| `SlicedPiece.cs` | Создаёт отдельные куски противника со своей физикой и суставами; управляет их ресурсами, повторной резкой и удалением. Содержит классы `SlicedPiece`, `PieceBody` и `PieceFamily`. |
| `PieceGrab.cs` | Позволяет брать руками куски и обломки без штатной ручки. |
| `TornLimb.cs` | Ставит штатные ручки на оторванную конечность по форме её меша и переносит на неё захват руки или телекинеза. |
| `TearJoints.cs` | Задаёт предел прочности суставам при двух захватах и восстанавливает его после отпускания. |
| `PieceLighting.cs` | Настраивает освещение кусков и поверхностей срезов через световые объёмы игры или обычные Unity-пробы. |
| `ItemCut.cs` | Режет оружие и предметы: меняет модель, коллайдеры, зоны урона, массу и центр тяжести. Создаёт обломки `ItemDebris`, поддерживает их захват и повторную резку. |
| `MeshReader.cs` | Получает доступную для обработки копию модели предмета, если обычное чтение вершин отключено. Для сжатых моделей использует специальный шейдер. |
| `CapTextures.cs` | Выбирает текстуры срезов по материалу предмета: дерево, камень, керамика, ткань и другие. Подготавливает материалы и карты рельефа. |
| `FireCut.cs` | Обрабатывает огненные разрезы: облегчение резки горячим клинком, обугливание, тлеющая кромка, дым и шипение. |
| `HotSteel.cs` | Создаёт раскалённый металлический срез и постепенно меняет его цвет по мере остывания. |
| `LogFilter.cs` | Подавляет повторяющееся предупреждение о вибрации звуковых эффектов, которое могло вызывать зависания с The Outer Rim. Остальные сообщения пропускает. |
| `Warmup.cs` | Заранее прогревает код и расчёт резки, уменьшая задержку при первом разрезе. |
| `ZandatsuRunner.cs` | Запускает корутины и отложенные действия, например завершение дыма или короткого замедления времени. |
